- Instalador Windows menor: verifica e reutiliza as bibliotecas de reprodução, baixando e preparando automaticamente o VLC oficial apenas quando necessário. Java continua incluído.
- Novas instalações usam Program Files, com permissão de administrador e opção de outra pasta. Atualizações mantêm a pasta e o contexto da instalação existente, preservando conta e configurações.
- Verificação de integridade, cancelamento, repetição e reparo das bibliotecas. A primeira preparação sem bibliotecas válidas requer internet.
- Desinstalação normal limpa arquivos, configurações e componentes em cache do Squi TV; essa limpeza não é executada durante atualizações.
- Busca da dashboard para canais, filmes e séries, com filtros, abertura dos detalhes/player, cancelamento de buscas antigas e reaproveitamento das listagens. A troca de canais fica restrita aos resultados de origem.
- Pacote de ícones reduzido, conservando os desenhos originais usados na interface.

Esta atualização é exclusiva do Windows. O Android permanece na v1.22.
