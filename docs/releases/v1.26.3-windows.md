# Windows — v1.26.3

- A fila de downloads de filmes e séries preserva o progresso ao adicionar itens. A falha de um episódio fica indicada na própria linha e os outros continuam na fila. Excluir um item em andamento cancela somente aquele arquivo.
- Downloads incompletos e respostas de erro do servidor recebem mensagens específicas. Quando disponível, o código HTTP aparece na linha do item.
- Ao abrir um download, tentar novamente ou trocar de episódio offline, o player verifica se o arquivo local está disponível. Se precisar baixá-lo de novo, o app avisa e preserva a posição salva.
- O diagnóstico de TV ao vivo e Multi-view indica quando o player ainda aguarda a superfície de vídeo antes de iniciar o LibVLC.

Atualização exclusiva do Windows. O Android permanece na v1.26.
