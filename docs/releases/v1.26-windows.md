# Windows — v1.26.0

- DNS próprio do aplicativo no login e na dashboard: Google, Cloudflare, tempo de resposta, seleção automática e opção de desativar. Não altera o DNS do Windows nem de outros aplicativos.
- Tela de preparação das categorias ao entrar na conta, com etapas separadas para canais, filmes e séries, cancelamento e nova tentativa. Os títulos e detalhes continuam carregando ao abrir cada catálogo.
- O formulário de login é preservado ao abrir o DNS ou retornar de uma sincronização interrompida. A dashboard e o aviso de atualização aguardam a preparação inicial.
- Backup com seleção dos grupos a exportar/importar e prévia antes de aplicar. Categorias, favoritos e nomes de exibição podem ser incluídos; grupos desmarcados são preservados e favoritos importados são somados aos existentes.
- Leitura de backups Windows completos anteriores preservada. Os novos arquivos seletivos exigem uma versão compatível e ainda não são intercambiáveis com o Android.

O instalador mantém a pasta e os dados da instalação existente. Novas instalações permitem escolher a pasta; as bibliotecas de reprodução são preparadas automaticamente quando necessário.
